Problem statement

Fake news spreads faster than corrections. Manually checking every article is impossible, so this project builds a system that automatically classifies a news article as real or fake, shows which words and writing patterns led to that decision, and uses a foundation model to explain the result in plain language with steps to verify it.

What the model learned

Fake articles in the data lean on sensational words ("breaking", "watch", "video"); real articles use attribution ("said", "spokesman") and precise days and dates.

System architecture

  1. User pastes a headline + article on the web page (HTML/CSS/JS).
  2. Flask API (/api/analyze) validates the input (guardrail: minimum 20 words).
  3. Preprocessing: leakage removal, lower-casing, contraction normalising, stop-word removal.
  4. TF-IDF + ML model ({{ metrics.best_model if metrics else "best model" }}, calibrated) → FAKE/REAL + confidence; word weights explain the decision.
  5. Amazon Comprehend → language, entities, sentiment (offline rules if AWS is not connected).
  6. Amazon Bedrock → structured explanation from an engineered prompt (offline template if not connected).
  7. Result page shows verdict, highlighted words, style signals, entities and the AI explanation.

Limitations

  • Trained on 2016–2017 (mostly US political) news, so it judges writing style, not whether facts are true.
  • Very short texts or other languages give unreliable results.
  • The output is a decision-support aid; a human should verify important claims.
